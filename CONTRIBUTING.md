# Contributing to Cruz

## Engineering Principles
All contributors and AI agents must adhere to the rules laid out in [`AGENTS.md`](./AGENTS.md).

### Workflow
1. Pull the latest `main` branch.
2. Create a feature branch: `feature/your-feature-name` or `fix/your-fix-name`.
3. Adhere to TypeScript strict types and shared design tokens.
4. Run automated tests and linting before committing.
5. Create atomic, well-documented commits.
