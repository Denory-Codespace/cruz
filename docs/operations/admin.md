# Cruz — Operations & Admin Guide

## 1. Operations Overview
The Cruz Admin Portal (`apps/admin-web`) provides real-time oversight of mobility operations in Nairobi.

## 2. Key Operational Views
1. **Live Operations Dashboard**:
   - Total drivers online vs. busy on trips.
   - Realtime Nairobi fleet map displaying active vehicles and ongoing passenger rides.
   - Current day Gross Merchandise Value (GMV) in KES and Platform Net Revenue.
2. **Driver Verification Queue**:
   - Review pending driver applications.
   - Verify Driver's License Number and National ID against uploaded documents.
   - One-click "Approve" or "Reject" with reason.
3. **Trip Management & Audit Logs**:
   - Search trips by Passenger, Driver, or Trip ID.
   - Inspect step-by-step `trip_events` history (timestamped checkpoints from request to completion).
4. **Financial Reconciliation**:
   - Review daily ledger transactions, driver payouts, and commission breakdowns.
